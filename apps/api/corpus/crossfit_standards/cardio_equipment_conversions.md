# Cardio Equipment Conversion Guide

This document provides the community-standard conversion ratios for substituting running
workouts with gym cardio equipment — rower (C2 Model D/E), Ski Erg, C2 BikeErg, and
Assault/Echo Bike. Use it when an athlete cannot run due to injury, weather, or equipment
availability, and needs an equivalent stimulus on a machine.

---

## Section 1: Distance Equivalency Table

When a workout is prescribed as a running distance (e.g., "Run 400m"), use these ratios
to substitute an equivalent machine distance. The table reflects the widely accepted
CrossFit community standard used by PRVN Fitness, CompTrain, and Training Think Tank.

| Run             | Row Erg (C2) | Ski Erg | C2 BikeErg | Assault / Echo Bike |
| --------------- | ------------ | ------- | ---------- | ------------------- |
| 200m            | 250m         | 200m    | 600m       | — (use calories)    |
| 400m            | 500m         | 400m    | 1,000m     | — (use calories)    |
| 800m            | 1,000m       | 800m    | 2,000m     | — (use calories)    |
| 1 mile (1,609m) | 2,000m       | 1,600m  | 4,000m     | — (use calories)    |

**Run → Row Erg**: The most settled ratio in the community — 1.25× (400m run = 500m row).
The rower recruits more total muscle mass but at lower intensity per muscle group, so a
slightly longer distance is needed for equivalent metabolic output.

**Run → Ski Erg**: Standard 1:1 ratio (400m run = 400m ski). The Ski Erg is upper-body
dominant but the cardiovascular demand closely mirrors running at equal distances.

**Run → C2 BikeErg**: 2.5× ratio (400m run = 1,000m bike) is the default used by PRVN and
CompTrain. Note that some programming uses 3× (400m run = 1,200m bike); if your affiliate
or programmer specifies a different ratio, follow theirs. The 2.5× ratio is the app
default.

**Assault / Echo / AirBike**: Distance conversions do not apply. The assault bike's distance
counter is not calibrated to any meaningful standard in competitive CrossFit. Always use the
calorie conversion table below for assault bike substitutions.

## Section 2: Calorie Equivalency Table

When a workout is structured for time and you need to substitute on a machine, use calorie
targets rather than distance targets. Machine calories (Cal/hr from flywheel resistance) are
a proxy for power output, not exact metabolic calories burned.

| Run    | Row Erg | Ski Erg | C2 BikeErg | Assault / Echo Bike |
| ------ | ------- | ------- | ---------- | ------------------- |
| 200m   | 10 cal  | 10 cal  | 8 cal      | 6–7 cal             |
| 400m   | 20 cal  | 20 cal  | 16 cal     | 12–14 cal           |
| 800m   | 40 cal  | 40 cal  | 32 cal     | 25–28 cal           |
| 1 mile | 80 cal  | 80 cal  | 64 cal     | 50–56 cal           |

**Important caveat**: Calorie output on ergs scales directly with athlete size and effort.
A 200 lb athlete pulling hard will accumulate calories faster than a 140 lb athlete pacing
conservatively. These numbers are stimulus equivalents — a guideline for matching the
intended intensity, not a precise caloric accounting. Ranges are shown where the community
consensus is divided (e.g., 12–14 cal assault bike for 400m run).

**Underlying per-metre rates**:

- Row Erg: ~1 cal per 20m of running
- Ski Erg: ~1 cal per 20m of running
- C2 BikeErg: ~1 cal per 25m of running
- Assault Bike: ~1 cal per 30m of running (full-body resistance makes calorie accumulation
  faster at equivalent perceived effort)

## Section 3: Machine Disambiguation

These four machines are distinct and require different conversion strategies.

**Row Erg (C2 Model D or E)**: The dominant rowing machine in CrossFit. When "rower" appears
in CrossFit programming, this is the assumed machine. Lower-body hip hinge with upper-body
pull. Calibrated wattage and a standard flywheel damper. Suitable for both distance and
calorie conversions.

**Ski Erg (C2 Ski Erg)**: Upper-body dominant, standing pull. Similar flywheel mechanics to
the rower. Calibrated distance and wattage. Suitable for both distance and calorie
conversions.

**C2 BikeErg**: Concept2's cycle ergometer. Lower-body dominant (pedals only, no arm
component). Flywheel and damper like a rower. Calibrated distance and wattage. Suitable for
both distance and calorie conversions, using the 2.5× distance ratio from the table above.

**Assault Bike / Echo Bike / AirBike**: Full-body air-resistance bike with moving handlebars.
The simultaneous arm and leg drive makes this machine higher demand per unit of time than the
BikeErg. The distance counter is not calibrated to any community standard — different models
and manufacturers display different numbers. Always express assault bike work in calories, not
distance. A 400m run substitutes to 12–14 calories on an assault bike.

**When a workout says "bike" without specifying**: If context makes it clear which bike is
available (e.g., the affiliate owns only assault bikes or only BikeErgs), use the
corresponding table. When in doubt, ask the athlete which bike they have access to. The
conversions differ meaningfully (1,000m BikeErg vs. 12–14 cal assault bike for a 400m run).

## Section 4: Which Conversion to Use When

**Use distance conversions when**:

- The original workout is prescribed as a distance ("Run 400m" as a standalone piece or
  within a chipper).
- The athlete wants to preserve the distance-based nature of the stimulus (e.g., pacing
  across a known distance matters for their training).

**Use calorie conversions when**:

- The workout is "for time" and matching intensity matters more than matching distance.
- The original movement is paired with other movements in a circuit and rest periods are
  built into the structure — calorie targets better match the intended work period.
- The athlete is substituting to an assault bike (distance conversions do not apply).
- When in doubt, calorie-based conversions tend to better match the physiological stimulus
  because they account for machine efficiency differences.

**Mixed WODs (e.g., Fran, Helen)**: When running appears in a WOD with other movements (like
Helen: 400m run + KB swings + pull-ups), either conversion is valid. The calorie target is
often preferred because it allows the athlete to adjust effort in real time using the machine
display.

---

## Section 5: Reversibility — Machine to Running

All conversions in this document work in both directions. To convert from a machine back to
running, invert the ratio.

**Examples**:

- 500m row ≈ 400m run
- 1,000m row ≈ 800m run
- 2,000m row ≈ 1 mile run
- 20 cal row ≈ 400m run
- 20 cal ski ≈ 400m run
- 16 cal BikeErg ≈ 400m run
- 12–14 cal assault bike ≈ 400m run

**Use case**: An athlete programming their own running-based workouts but training at a gym
with only a rower can reverse-engineer equivalent machine work from the running prescription.
The same ratios apply — only the direction changes.
